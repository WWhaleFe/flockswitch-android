# 스크린샷 계획 (Google Play, 0.9.0)

## 실제로 올릴 파일 (2026-11-10 결정)

개발자가 직접 캡처한 `android/img/ForStore1~6.JPG`(1080×2503, 원본은 저장소 밖)를 씁니다. 원본은 긴 변이 짧은 변의 2.32배라 Play 규격(2배 이하)을 넘기 때문에, 내용은 자르지 않고 **양옆을 각 줄의 가장자리 색으로 늘려** 1252×2503(24비트 PNG, 투명도 없음)으로 맞춘 사본을 `listing/phone/`에 두었습니다. 6번은 왼쪽 가장자리에 대기 효과가 걸려 있어 오른쪽 가장자리 색으로 양옆을 채웠습니다.

| 순서 | 파일 | 화면 |
|---|---|---|
| 1 | `phone/ForStore1.png` | 홈 탭 |
| 2 | `phone/ForStore2.png` | (원본 2번) |
| 3 | `phone/ForStore3.png` | 진동 설정 창 |

Play Console → 스토어 등록정보 → **휴대전화 스크린샷**에 이 순서대로 올립니다(한국어·영어 목록 모두 같은 이미지 사용 가능). 폴더블을 펼친 화면(태블릿 칸)은 Z Flip이라 없으며, 태블릿 칸은 비워 두어도 됩니다.

아래는 처음 세운 캡처 계획입니다(참고용).


휴대전화에서 직접 캡처합니다. 캡처한 파일은 이 폴더 아래 `phone/`, `tablet/`에 넣으면 됩니다 (`phone/01-home.png` 같은 이름).

## Play 규격 (업로드 전 확인)

| 항목 | 규격 |
|---|---|
| 형식 | PNG(24비트, 투명도 없음) 또는 JPEG, 장당 8MB 이하 |
| 크기 | 각 변 320~3840px, **긴 변이 짧은 변의 2배 이하** |
| 휴대전화 | 2~8장. 추천·검색 노출을 받으려면 **1080px 이상, 9:16(세로) 4장 이상** |
| 태블릿 7인치·10인치 | 각 최대 8장. 10인치는 각 변 1080px 이상. 폴더블을 펼친 화면 캡처를 여기에 씁니다 |

**주의: 요즘 휴대전화 화면(예: 1080×2340, 19.5:9)은 긴 변이 2배를 넘어 그대로는 올라가지 않습니다.** 상태 표시줄·내비게이션 바를 잘라 9:16(1080×1920)으로 맞추세요. 맥에서:

```sh
# 가운데 기준으로 1080×1920으로 자름 (sips -c 높이 너비)
sips -c 1920 1080 phone/01-home-raw.png --out phone/01-home.png
# 위쪽 상태 표시줄만 빼고 자르려면: --cropOffset <위에서 뺄 px> 0
sips -c 1920 1080 --cropOffset 120 0 phone/01-home-raw.png --out phone/01-home.png
```

폴더블을 펼친 화면(예: 2176×1812)은 비율이 2배 이내라 그대로 태블릿 칸에 올릴 수 있습니다.

## 캡처 전 준비

- 언어: 한국어 목록용은 기기 언어를 한국어로, 영어 목록용은 English로 바꿔 같은 화면을 두 번 캡처합니다 (앱은 기기 언어를 따름).
- 마스터 마우스가 **이 기기에 연결된 상태**여야 홈 탭에 마우스 이름·채널·지금 전환 버튼이 나옵니다. 예: 이 기기 = 채널 3.
- 상태 표시줄에 다른 앱 알림, 시계 외 개인 정보가 보이지 않게 합니다 (방해 금지 모드 권장). 위 명령처럼 상태 표시줄을 잘라 내도 됩니다.
- 다크 모드/라이트 모드는 한 가지로 통일합니다.
- 접근성 서비스 공개 창(“접근성 서비스 사용 안내”)은 스크린샷에 넣지 않습니다(심사 영상용).

## 휴대전화 (세로, 9:16) — 6~8장

| # | 파일 | 화면 | 캡처 방법 | 캡션 (ko) | 캡션 (en) |
|---|---|---|---|---|---|
| 1 | `phone/01-home` | 홈 탭 | 마우스가 이 기기에 있을 때. 상태(마우스 이름), “이 기기는 채널 3”, 지금 전환 1·2 버튼이 보이게 | 버튼 한 번으로 마우스와 키보드를 함께 | One button moves mouse and keyboard together |
| 2 | `phone/02-buttons` | 버튼 탭 위쪽 | 휠 모드 전환 버튼에 채널 1, 제스처 버튼의 방향별 채널을 몇 개 켠 상태 | 버튼과 제스처 방향마다 이동할 채널 | A channel for each button and gesture |
| 3 | `phone/03-edges` | 버튼 탭 → 화면 모서리에서 전환 | 왼쪽 = 1, 오른쪽 = 2, 머무는 시간 0.5초, 전환 대기 효과 펼친 상태 | 화면 가장자리로 밀면 그쪽 컴퓨터로 | Push the pointer to an edge to switch |
| 4 | `phone/04-countdown` | 전환 대기 효과가 그려진 순간 | 버튼 탭에서 링 또는 네온 레이저를 고르고 **미리 보기**를 누른 직후 캡처 (또는 실제로 가장자리에 포인터를 대고 기다리는 동안) | 전환 대기 효과 8가지와 랜덤 | Eight countdown effects, or random |
| 5 | `phone/05-devices` | 장치 탭 | 마스터 마우스(자동 선택)와 함께 이동할 키보드에 체크 | 함께 이동할 키보드와 장치 선택 | Pick what moves along with the mouse |
| 6 | `phone/06-haptics` | 일반 탭 → 진동 설정… 대화상자 | 진동 사용 켬, 세기 75%, 떠날 때·돌아왔을 때 켬 | 진동 모터가 있는 마우스의 진동 설정 | Haptics for mice with a motor |

1~4번이 가장 중요합니다(목록에서 먼저 보임). 최소 4장은 1080×1920으로 맞추세요.

## 캡션

Play는 캡션 입력란이 없습니다. 캡션을 넣고 싶으면 이미지 위·아래에 글자를 얹은 별도 이미지를 만들어야 합니다. 그대로 올려도 심사에는 문제없습니다. 캡션에는 다른 회사 상표(Logitech, MX Master 등)를 넣지 않았습니다. 화면에 실제로 보이는 장치 이름(예: “MX Master 4”)은 그대로 두어도 됩니다.
